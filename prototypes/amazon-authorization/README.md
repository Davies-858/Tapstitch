# Tapstitch Amazon authorization prototype

Interactive prototype for the Stores authorization page.

## Included flows

- Existing Shopify connected card
- Separate TikTok Shop authorization entry
- Amazon permissions introduction
- North America (US, CA, MX) and Europe marketplace selection
- Seller Central authorization handoff simulation
- Loading, success, error, retry, back, and cancel-confirmation states
- Responsive desktop and mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal and click the Amazon card.

## Notes

This is a front-end prototype. Amazon OAuth and production credentials are intentionally simulated.
